# FocalAfford

> 状态：进行中。课题已确定，不再讨论换题；当前尚无本方法实验结果。

## 当前问题

FocalAfford 研究语言引导三维功能部位定位中的局部视觉迁移：局部观察负责看清细小功能区域，整物体任务语境负责解释局部几何，局部修正蒸馏只向三维学生传递局部教师相对全局教师真正有增量的知识。

当前需要尽快验证三个可观察问题：

1. 高分辨率几何锚定局部观察是否优于全局区域预测和普通裁剪；
2. 整物体任务语境是否在相同局部视觉、文字和位置条件上继续带来增量；
3. 优势加权局部修正蒸馏是否优于直接蒸馏和相同区域的 GT 重加权。

## 当前判断

- **已确定**：FocalAfford 是当前课题；首要框架为 GEAL，首要数据集为 LASO。
- **已核实起点**：GEAL 官方代码提供二维教师、三维学生、12 个固定视角渲染和两阶段训练入口；LASO 官方数据提供 train/val/test 文件。
- **待验证假设**：局部重渲染、全局语境和修正蒸馏的增量均未得到实验支持。
- **停止或收缩条件**：局部观察若不能超过全局区域预测和普通裁剪，则停止继续堆叠语境与蒸馏模块；后续模块只在前置现象通过时运行。
